# Water Payments MVP

Локальное MVP приложения учета платежей и расходов.

## Стек

- Node.js HTTP-сервер без внешних npm-зависимостей.
- SQLite-база в `db/water.sqlite`.
- Python-скрипты для инициализации SQLite, smoke-check и рендера карточек.
- Vanilla HTML/CSS/JS.

## Быстрый старт

```bash
npm run init-db
npm test
npm run dev
```

Данные ведутся в SQLite через админку и ботов. Для локальной работы используйте существующий `db/water.sqlite` или загрузите актуальную копию через админский блок "База SQLite".

После запуска:

- публичный дашборд: `http://localhost:4173/`;
- админка: `http://localhost:4173/admin`;
- пароль администратора по умолчанию: `admin`.

Пароль можно заменить переменной окружения:

```bash
ADMIN_PASSWORD="new-password" npm run dev
```

Для фиксации расчетного месяца:

```bash
AS_OF_MONTH=2026-06 npm run dev
```

Реквизиты кнопки "Как оплатить?" в Telegram/MAX-ботах можно переопределить переменными окружения:

```bash
SBP_PAYMENT_RECIPIENT="Получатель" SBP_PAYMENT_PHONE="+79990000000" SBP_PAYMENT_AMOUNT=1000 npm run dev
```

Банк получателя в СБП-подсказке фиксирован: нужно обязательно выбрать `Альфа-Банк`.

## Telegram-бот

Бот запускается вместе с сервером, если заданы переменные:

```bash
TELEGRAM_BOT_TOKEN="token-from-botfather" TELEGRAM_ADMIN_IDS="123456789" npm run dev
```

Основные команды и кнопки: `/debts`, `/house 12`, `/link`, `/me`, `/pay 12 1500 комментарий`, "Сводка", "Как оплатить?". Сводка отправляет карту улицы и общий список должников. Если дом не привязан, `/link` или кнопка "Привязать дом" просит ввести только номер дома без персональной ссылки `/h/...`, после чего отправляет заявку администратору на согласование. Дата платежа ставится автоматически текущим днем. Для платежа обязательно приложить фото или PDF чека; если дом привязан к Telegram-аккаунту, через кнопку "Отправить платеж" можно вводить только сумму. Администратор может переслать боту сообщение с чеком и подписью вроде "Уютная 34": бот спросит сумму и сразу внесет платеж. Если адреса в пересланном сообщении нет, бот спросит дом и сумму.

К одному дому можно привязать несколько Telegram- и MAX-аккаунтов. Каждый аккаунт остается отдельной записью и может отправлять платежи по тому же дому.

При успешном добавлении оплаты все привязанные к дому аккаунты получают уведомление в Telegram/MAX. Автор подтвержденной заявки получает одно персональное подтверждение, без дубля в том же боте.
